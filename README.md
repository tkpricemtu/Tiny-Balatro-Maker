# Tiny-Balatro-Maker
This program takes a Balatro.exe from Steam and installs a mod to make it more playable on tiny screens (640x480, tested on a 2.8 inch screen but will work on larger). Note that I am not a good programmer, so this is what I have so far. 
Instructions:

-Download this repo to a folder of your choice

-Find your Steam version of "Balatro.exe" and copy it to the root of this project folder (same location as "tinyBalatroMaker.m")

-Download the font at this link: https://www.atozfont.com/download/noto-sans-condensed-bold

-Extract the font and drag it to the "Images" folder (so "Images/NotoSans-CondensedBold.ttf" exists)

-Run "tinyBalatroMaker.m"

This will create a new version of "Balatro.exe" that can be dragged into the Portmaster folder, or can be used in creating an apk for Andriod installations.
